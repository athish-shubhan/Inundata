# data/hitoyoshi/processed

Generated by `scripts/run_pipeline.py` from `data/hitoyoshi/raw/`. Committed so the API and dashboard run straight after `pip install -r requirements.txt`, without hitting any external service.

- `features.tif`: 15-band float32 GeoTIFF on the 30 m analysis grid (EPSG:32652, 508 × 305). Band descriptions name each layer: predictors (`elev_m`, `slope_deg`, `hand_m`, `river_dist_m`, `tpi_m`, `log_flow_acc`, `ndvi_pre`, `ndwi_pre`, `ndbi_pre`), label (`flood_fraction`, `flooded`), and diagnostics (`permanent_water`, `cloud`, `ndwi_change`, `proxy_label`). Output of `src/geo/fusion.py`.
- `risk.tif`: calibrated flood probability per cell. `risk` is the final model (what the API serves); `risk_oof` is the cross-fitted out-of-fold score used for evaluation. The `operating_threshold` tag is the HIGH-band cut-off.
- `metrics.json`: spatial and random CV for every candidate, per-fold metrics, calibration and reliability table, proxy-label check, permutation importance, and the caveat shown wherever the model's output appears.
- `model.joblib`: the selected classifier, its isotonic calibrator, feature list and threshold, for re-scoring the grid.
- `error_analysis.csv`: out-of-fold false positives and negatives with their terrain values, output of `src/ml/evaluate.py`.

All GeoTIFFs open directly in QGIS. Regenerate with `python scripts/run_pipeline.py` (about 2.5 minutes).
