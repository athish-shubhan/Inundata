# data/processed

Generated by `scripts/run_pipeline.py`. Committed here so the repo runs immediately after `pip install -r requirements.txt` without waiting on external APIs.

- `features.csv`: the fused multimodal feature table (480 grid cells x 17 columns), output of `src/geo/fusion.py`.
- `model.pkl`: the selected, trained model (`joblib` dump of `{model, name, features}`), output of `src/ml/train.py`.
- `metrics.json`: cross-validated performance for both candidate models, the selected model, feature importance, and the labeling caveat.
- `error_analysis.csv`: in-sample false positive/negative grid cells, output of `src/ml/evaluate.py`, for spatial error inspection only (not a generalization estimate, see `metrics.json` / README §9 for that).
- `terrain/*.tif`: intermediate GeoTIFFs (DEM, slope, HAND, river distance, NDWI change, rainfall) for external GIS inspection (e.g. QGIS).

Regenerate any of the above with `python scripts/run_pipeline.py` (takes ~5 seconds).
